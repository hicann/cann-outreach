# ranxing-empower-training 活动说明

为支撑区域开发者更好地学习和使用昇腾AI平台，广东区域创新中心联合CANN社区开展
「ranxing-empower-training」专项培训活动，赋能开发者掌握昇腾软硬件技术，进行活动任务提交。

## 目录结构

```
ranxing-empower-training/
└── {gitcode用户名}/
    └── TanhCustom/      # 任务作品（自定义算子工程）
```

## 提交步骤

1. 在 `ranxing-empower-training/` 下创建以 **gitcode用户名** 命名的文件夹
2. 在用户名文件夹下创建以 **任务名称** 命名的文件夹（如 TanhCustom）
3. 按任务要求提交算子代码（op_host / op_kernel / framework）
4. 提交 Pull Request 到本仓库
