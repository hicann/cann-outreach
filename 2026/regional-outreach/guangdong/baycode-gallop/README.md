# baycode-gallop 活动说明（湾码奔腾）

为支撑区域开发者更好地学习和使用昇腾AI平台，广东区域创新中心联合CANN社区开展
「湾码奔腾（baycode-gallop）」专项培训活动，赋能开发者掌握昇腾软硬件技术，培养动手实测能力。

## 目录结构

```
baycode-gallop/
└── {gitcode用户名}/
    └── {任务名称}/
```

## 提交步骤

1. 在 `baycode-gallop/` 下创建以 **gitcode用户名** 命名的文件夹
2. 在用户名文件夹下创建以 **任务名称** 命名的文件夹
3. 按任务要求提交作品内容
4. 提交 Pull Request 到本仓库
