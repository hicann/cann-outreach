## 算子: op_10_gelu

本算子基于 Ascend C 实现 GELU 激活函数，支持 float16 和 float32 两种数据类型，输入支持任意维度 ND 张量，输出 Shape 和数据类型与输入保持一致。Kernel 采用标准 GELU 精确公式 0.5*x*(1+erf(x/sqrt(2))) 进行逐元素计算，相比 tanh 近似方式具有更好的精度表现。Host 侧完成 Shape 推导、数据类型推导以及 Tiling 参数计算，并根据输入元素总量进行多核任务划分；Kernel 侧根据 blockIdx 获取当前 AI Core 的处理区间，并通过 UB 分块完成数据搬入、计算和结果搬出，从而兼顾大规模输入场景和硬件资源利用率。针对 float16 数据，为降低连续乘加及 erf 运算产生的累计舍入误差，计算过程中先将 half 数据转换为 float32，在 FP32 精度下完成 GELU 运算后再转换回 float16，从而提高结果精度。针对输入长度非 32 字节对齐的情况，尾块采用支持非对齐的数据搬运方式处理，避免尾部元素丢失或越界访问。因此该实现能够兼容不同维度、不同长度以及非对齐输入场景，并通过多核并行、UB 分块和 FP16 中间精度提升，在保证计算正确性的同时满足题目对 float32 和 float16 的精度要求。
