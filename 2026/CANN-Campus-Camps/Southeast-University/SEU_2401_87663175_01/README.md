## 算子: op_01_sub

在功能正确的基础上，本实现针对固定输入规模进行了性能优化。通过采用 8 核并行计算，将每个核负责的数据进一步划分为两个 1024 元素的数据块，并利用 MTE2、Vector 和 MTE3 流水之间的并行关系实现数据搬入、矢量计算和结果搬出的重叠执行。同时采用 Static Tensor 方式进行 UB 内存管理，减少 TPipe、TQue 及动态 Buffer 管理产生的额外开销，并使用底层 Vector Sub 接口和精细化流水同步进一步降低控制开销。经过多轮核数、Tile 大小、双缓冲方式及同步策略调优，最终算子执行时间由约 2.3 μs 优化至约 1.72 μs。
