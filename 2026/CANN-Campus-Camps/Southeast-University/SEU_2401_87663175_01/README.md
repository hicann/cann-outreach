## 算子: op_04_square

本项目实现 Ascend C Square 自定义算子，支持 float16、float32 以及任意维度 ND Tensor。针对输入长度非 32B 对齐的问题，采用对齐主块与非对齐尾块分离策略，主路径使用 DataCopy，尾部使用 DataCopyPad，从而保证任意 Shape 下计算正确。

性能优化方面，根据输入规模和 AIV 核数动态完成多核 Tiling，并结合 UB 容量进行二级分块。Kernel 使用 Vector Mul 完成原地平方计算，并通过双缓冲和输入输出 UB 复用降低片上存储开销，提高 MTE 与 Vector 流水并行能力。同时减少主循环中的分支、Mask 设置及 Queue 管理开销。最终验证集 3/3 通过，输出误差率均为 0%。
