## 算子: op_02_mul

算子采用 Ascend C 实现逐元素乘法，输入为同形状的 x、y，输出为 z=x*y，支持 float16 和 float32 数据类型。Tiling 阶段将数据按 AI Core 数量进行分块，每个 Core 再将数据切分为多个 Tile；Kernel 通过 UB 搬运输入数据，调用 AscendC::Mul 完成计算后写回全局内存，并使用双缓冲队列提升数据搬运与计算效率。
