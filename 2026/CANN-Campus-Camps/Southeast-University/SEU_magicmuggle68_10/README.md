## 算子: op_10_gelu

本算子基于 Ascend C 实现 GELU 激活，支持 FP16、FP32 和任意 ND 输入，并兼容非 32B 对齐场景。
- Host 侧：读取张量元素总数和数据类型，根据数据规模动态设置 AIV 核数，避免小张量启动无效核心。
- Kernel 侧：将输入按多核切分，每核再以 4096 个元素为 Tile 分块处理，通过 DataCopy/DataCopyPad 完成对齐及非对齐搬运。
- FP16：调用 Ascend C 官方 GELU 默认精度实现，并通过 TQueBind 复用 VECIN/VECOUT 缓冲区。
- FP32：使用经过拟合的高精度有理函数近似正态分布函数，以 Exp、乘法和除法等向量指令完成计算，最大绝对拟合误差约为 3.6e-5。
- 性能优化：采用多核并行、动态核数、4096 Tile、双缓冲、UB 内存复用及 Counter Mask，减少核启动、循环、临时空间和重复 Mask 配置开销。
