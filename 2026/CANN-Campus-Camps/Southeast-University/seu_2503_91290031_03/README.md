## 算子: op_03_relu

ReLU 激活算子介绍
算子功能
实现 ReLU 激活函数：y = max(0, x)。对输入张量中的每个元素，若大于0则保持不变，否则置为0。

输入输出
类型	参数	形状	数据类型
输入	x	(8, 2048)	float16 / float32
输出	y	(8, 2048)	float16 / float32
计算逻辑
text
y[i] = max(0, x[i])
技术特点
双缓冲流水线：BUFFER_NUM = 2，实现数据搬运与计算并行

多核自适应：大数据量自动启用多核并行，小数据量单核处理

Tiling分块：根据硬件UB大小动态调整分块策略

实现方式
基于 AscendC::Max 指令，将输入与全零张量逐元素比较取最大值，高效完成激活计算。
