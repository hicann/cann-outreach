## 算子: op_02_mul

支持 float16 和 float32，输入输出形状为 (8, 2048)。Host 侧完成 Shape、DataType 推导及 Tiling 划分，并针对不同数据类型采用差异化单核处理规模，以平衡核启动开销与并行效率。Kernel 侧采用多核并行计算，将数据由 GM 搬运至 UB，使用 Vector Mul 指令完成计算后回写 GM。实现中采用静态 LocalTensor、合理规划 UB 地址并保留必要的事件同步，降低框架、访存及 Bank Conflict 开销，从而提升固定规模场景下的执行性能。
