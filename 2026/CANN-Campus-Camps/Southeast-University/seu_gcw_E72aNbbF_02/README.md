## 算子: op_10_gelu

基于 Ascend C 编程语言进行自定义工程算子开发，在昇腾 NPU 硬件上实现 GELU 激活算子。

GELU（Gaussian Error Linear Unit，高斯误差线性单元）是一种在深度学习中广泛使用的激活函数，由 Dan Hendrycks 和 Kevin Gimpel 在 2016 年提出。GELU 结合了 ReLU 的稀疏激活特性和平滑的非线性特性，在 Transformer 架构（如 BERT、GPT）中表现优异，已成为自然语言处理领域的标准激活函数。
