## 算子: op_01_sub

本算子采用 Ascend C 实现矢量减法 z=x-y。

首先在 Host 侧计算输入张量的总元素数量，并根据可用 AI Core 数量进行数据划分，同时确定 Tile 大小和数量。

Kernel 侧采用多核并行，每个 AI Core 负责一段连续数据。计算时通过 DataCopy 将 x、y 从 GM 搬运到 UB，再利用 Vector Sub 指令进行逐元素减法，最后将结果从 UB 搬回 GM。

算子分别支持 FP32 和 FP16 两种数据类型，通过不同 Kernel 进行处理。

针对本题较小的数据规模，通过增大 Tile、减少 Tile 循环次数，并限制 Core 数量，降低数据搬运和调度开销，从而提高整体执行效率。
