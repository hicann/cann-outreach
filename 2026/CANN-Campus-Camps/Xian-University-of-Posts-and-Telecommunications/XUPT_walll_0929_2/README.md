## 算子: op_03_relu

本算子基于 Ascend C 实现 ReLU 激活函数，计算公式为 y = max(0, x)，支持 float16 和 float32 输入。Host 侧根据输入形状、数据类型、可用核数和 UB 缓冲区大小计算 tiling 参数，采用最多 8 个 Vector Core 并行执行。
Kernel 侧将每个核负责的数据继续切分为多个 Tile，使用双缓冲队列完成数据搬入、ReLU 计算和结果搬出。对于形状为 (8, 2048) 的输入，8 个核各处理 2048 个元素，每核分两次处理 1024 个元素；尾部不足一个 Tile 的数据按实际长度处理。
