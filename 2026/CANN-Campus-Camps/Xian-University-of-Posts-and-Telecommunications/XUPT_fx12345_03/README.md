## 算子: op_03_relu

- 原生 PyTorch 算子：`torch.nn.functional.relu`
- 计算公式：\(y = max(0, x)\)，逐元素激活，输入张量每个元素和 0 比较，取较大值作为输出
- 核心逻辑：元素大于 0 保留原值，小于等于 0 置 0；无额外参数，单输入单输出。
- 分片 (Tiling) 目的：把大张量切分成多个小块 tile，降低片上缓存占用，分块迭代计算，避免内存溢出，适配硬件计算单元。
