## 算子: op_04_squar

一、赛题背景
Square（平方）算子对输入张量的每个元素计算其平方值（y = x × x），是最基础的元素级算术算子之一。它广泛应用于损失函数（如 MSE 中的平方项）、距离度量（平方和）、特征工程以及各类数值计算场景，是深度学习框架中覆盖率最高的基础算子之一。

二、算子功能描述
Square 算子对输入张量的每个元素独立计算平方：y = x × x。输出张量与输入张量的形状、数据类型完全相同，计算结果恒为非负。
