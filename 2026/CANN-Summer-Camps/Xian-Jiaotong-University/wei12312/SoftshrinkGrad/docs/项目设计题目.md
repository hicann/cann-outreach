# 项目设计题目：基于 Ascend C 的 SoftshrinkGrad 算子开发

**CANN SUMMER CAMPS 2026 · XJTU · 第16组**

## 一、项目题目

基于 CANN/Ascend C 完成 SoftshrinkGrad 算子的分析、设计、实现与验证。

## 二、项目目标

1. 理解 Softshrink 激活函数及其反向传播公式。
2. 完成 SoftshrinkGrad 的算子原型、Shape/Dtype 推导和 Tiling 设计。
3. 使用 Ascend C 实现支持 FLOAT、FLOAT16、BFLOAT16 的 AI Core Kernel。
4. 支持动态 shape、标量、空 Tensor 和非 32 Byte 对齐尾块。
5. 提供可复现的 CPU 参考测试和 ACLNN 端到端样例。
6. 完成算子设计文档、项目说明、测试报告等任务交付件。

## 三、输入输出

| 名称 | 类型 | 说明 |
|---|---|---|
| gradOutput | Tensor | 上游梯度 |
| self | Tensor | Softshrink 正向输入 |
| lambd | FLOAT 属性 | 阈值，默认 0.5，要求大于等于 0 |
| gradInput | Tensor | 对 self 的梯度 |

输出与 `gradOutput`、`self` 的 broadcast 结果同 shape，dtype 与
`gradOutput` 一致。核心 AI Core 算子接收 ACLNN 层预处理后的同 shape、同 dtype
输入。

## 四、项目内容

### 4.1 Host 侧

- 定义算子输入、输出、属性和平台配置。
- 校验输入长度和 `lambd`。
- 完成输出 Shape 与数据类型推导。
- 根据元素总数选择 1～40 个 AI Vector 核。
- 生成每核长度、Tile 长度和阈值 Tiling 数据。

### 4.2 Kernel 侧

- 采用 GM→UB→Vector→GM 的流水线。
- 使用双缓冲隐藏搬运时延。
- 通过 `Abs + CompareScalar + Select` 完成掩码计算。
- FLOAT16/BFLOAT16 转为 FLOAT 进行比较，输出时再转换回原 dtype。
- 最后一块使用 `DataCopyPad` 按有效字节搬运，避免越界写入。

### 4.3 测试

- CPU 参考测试：边界、广播、标量、空 Tensor、NaN、非法参数。
- ACLNN 样例：在 Atlas A2/A3 环境编译安装后执行。
- 精度标准：逐元素结果与 CPU golden 一致；该算子仅选择或置零，不引入数学近似。
