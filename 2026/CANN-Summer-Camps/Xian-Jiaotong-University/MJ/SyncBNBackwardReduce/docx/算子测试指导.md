## 2. UT Tiling 测试

### 2.1 测试内容

验证 tiling 函数的正确性：

- TilingKey 选择是否正确（float16=0, float32=1, bfloat16=2）
- TilingData 参数（totalNum, blockFactor, ubFactor）计算是否正确
- 单核/多核切换逻辑（MIN_SPLIT_THRESHOLD=1024）

### 2.2 Tiling 计算公式

```
elemPerBlock = 32 / typeLen   (float16/bf16=16, float32=8)
bytesPerElem = (FLOAT) ? 48 : 72
ubFactor = (ubSize / bytesPerElem / elemPerBlock) * elemPerBlock
  → float16/bf16: (262144/72/16)*16 = 3632
  → float32:      (262144/48/8)*8   = 5456

totalNum < 1024 → useCoreNum = 1
totalNum >= 1024 → useCoreNum = min(64, CeilDiv(totalNum, elemPerBlock))
blockFactor = CeilAlign(max(CeilDiv(totalNum, useCoreNum), elemPerBlock), elemPerBlock)
```

## 3. UT Kernel 测试

### 3.1 测试内容

在 CPU 模拟环境（tikicpulib）下验证 kernel 计算逻辑的正确性：

- 验证 3 种 dtype 的 cast + 计算路径
- 验证单核/多核数据切分
- 通过 golden 数据比对验证精度

### 3.2 测试数据生成

测试数据由 `gen_data.py` 生成，位于 `code/tests/ut/op_kernel/sync_batch_norm_backward_reduce_data/` 目录。

**Golden 计算算法**：

```python
dy_mean = mean * sum_dy
sum_dy_xmu = sum_dy_dx_pad - dy_mean
y = sum_dy_xmu * invert_std
```

## 4. aclnn 端到端测试

### 4.2 执行方法
