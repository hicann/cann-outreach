# CANN训练营2026暑期季

## 活动介绍
为支撑高校开发者更好地学习和使用昇腾AI平台，CANN社区联合高校开展CANN训练营暑期季活动，助力开发者快速成长。

## 目录结构
```
CANN-Summer-Camps/
├── README.md                                                 # 本文档
├── Xian-Jiaotong-University/              # 活动高校名称
│       └── {gitcode用户名}/                                   # 开发者gitcode账号
│           └── {任务名称}/                                    # 贡献内容
├── Northwestern-Polytechnical-University/                    # 活动高校名称
│       └── {gitcode用户名}/                                   # 开发者gitcode账号
│           └── {任务名称}/                                    # 贡献内容
```

## 提交规范

### 命名规范
- **活动目录**：格式为 `{高校名称}`，单词间用连字符分隔
  - 示例：`Xian-Jiaotong-University`、`Northwestern-Polytechnical-University`
- **用户目录**：使用 gitcode 用户名
- **任务目录**：使用任务名称，如 `TanhCustom`

### 提交步骤
1. 在对应 **活动目录** 下创建以 **高校名称** 命名的文件夹
2. 在活动文件夹下创建以 **gitcode用户名** 命名的文件夹
3. 在用户名文件夹下创建以 **任务名称** 命名的文件夹
4. 按照任务要求提交贡献内容
5. 提交 Pull Request 到本仓库
