# 学员代码提交目录

请在本目录下新建以本人 GitCode 用户名命名的子目录，将 `../Template/` 中的两个 Python 文件复制进去，再按中文 `TODO` 注释补全 `matmul_add_relu.py`。五处待补全代码均位于上下两行 `# --------------------------------` 之间，请替换其中的 `pass`。

例如，在上一层题目目录中执行；将 `your_gitcode_name` 换成自己的用户名：

```bash
cp -r Template PR_code/your_gitcode_name
python PR_code/your_gitcode_name/test_matmul_add_relu.py --device 0
```

通过验证后，将自己的子目录提交到 GitCode。此 `README.md` 同时用于确保 `PR_code/` 在 Git 中保留，请勿删除。
