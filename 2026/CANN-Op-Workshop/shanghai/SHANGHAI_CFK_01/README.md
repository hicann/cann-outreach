## 算子: op_01_sub

Sub 实现 `z = x - y`。Host 启动逻辑校验单张量、同形状和同数据类型，依据总元素数、固定 2048 元素 tile 及可用核数生成 tiling。Kernel 为每个核计算独立区间，使用 x/y/z 三队列双缓冲，经 `DataCopyPad` 搬运、`Sub` 向量计算和写回完成尾块处理；按 dtype 分发 float32、float16，适用于 ND `(8, 2048)` 输入。
