## 算子: op_02_mul

Mul 实现 `z = x * y`。Host 侧根据输入长度、数据类型和 UB 容量计算有效 AIV 核数、每核长度与 tile 长度，并完成输出 shape/dtype 推导。Kernel 按核偏移处理连续数据，采用 x/y/z 三队列双缓冲，使用 `DataCopyPad` 搬入搬出并调用 `Mul` 完成分块计算，支持 float32 与 float16 的 ND `(8, 2048)` 输入。
