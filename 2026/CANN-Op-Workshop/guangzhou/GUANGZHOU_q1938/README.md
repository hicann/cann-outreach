## 算子: op_01_sub

算子: op_01_sub
UB切分按32B对齐
在AscendC中，统一缓冲区（UB） 的数据切分需要满足 32字节对齐 要求。这意味着：
每次从Global Memory搬运到UB的数据块大小必须是32B的整数倍

对于 float 类型（4字节），tileLength 应为 8的倍数（8 × 4B = 32B）

确保内存访问效率，避免非对齐访问带来的性能损失

Tiling策略：totalLength对齐到BLOCK_SIZE的整数倍
BLOCK_SIZE 通常指单次搬运的最小粒度（如32B或硬件特定的对齐单位）
总数据长度 totalLength 需要对齐到 BLOCK_SIZE 的整数倍

若原始数据不满足对齐，需在Host侧进行 padding填充，补齐到整数倍后再传入核函数

对齐后可保证每个核处理的数据块大小一致，简化边界处理逻辑
