## 算子: op_01_mul

本项目基于Ascend C原生算子开发框架，在昇腾NPU硬件上实现了逐元素矢量乘法算子（z = x * y）。采用多核并行计算架构，将全局数据按AI Core数量均分；单核内采用分块双缓冲机制，通过8个tile分块配合2组缓冲完成数据搬运与计算的调度.基于TPipe队列管理片上UB内存，实现Global Memory与Local Memory之间的高效数据搬运，严格遵循内存分配-使用-释放流程，避免内存泄漏。调用AscendC原生Mul矢量计算接口，实现单指令多数据的并行乘法运算，充分利用NPU向量计算单元。
