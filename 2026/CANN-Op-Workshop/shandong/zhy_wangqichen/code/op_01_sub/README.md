## 算子实现介绍

1.数据平铺：把 (8, 2048) 当作 16384 个连续元素，不再按行切，避免每核只做一行 2048 元素的尴尬。
2.双缓冲（BUFFER_NUM=2）：TQue 深度设为 2，让下一次的 CopyIn 与当前 Compute 重叠，DataCopy 和 Sub 可以并行，这是提速最关键的一步。
3.Tile 粒度增大到 2048：每核循环次数从 8 次降到 1 次（8 核时每核 2048 元素，正好 1 个 tile），循环开销几乎消失。
4.核数用 availableCoreNum：不再硬编码 8，让它按实际可用核数均分。
