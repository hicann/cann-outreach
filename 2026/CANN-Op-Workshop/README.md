# 算子实操工坊

## 活动介绍
为支撑各地域开发者更好地学习和使用昇腾，CANN开源社区联合各地域组织线下开展算子工坊实操活动，通过专家授课、算子实操、培养持续贡献者，牵引高质量社区贡献。

## 目录结构
```
CANN-Op-Workshop/
├── README.md                             # 本文档
├── shanghai/                             # 上海地域活动
│   └── {gitcode用户名}/                  # 开发者gitcode账号
│       └── {任务名称}/                    # 贡献内容
├── beijing/                              # 北京地域活动
├── guangzhou/                            # 广州地域活动
└── hangzhou/                             # 杭州地域活动
```

## 提交规范

### 目录结构要求
每个任务提交目录结构如下：
```
{区域}/
└── {gitcode用户名}/
    └── {任务名称}/
        ├── xxxx                      # 任务代码

```

### 提交步骤
1. 在对应 **区域目录** 下创建以 **gitcode用户名** 命名的文件夹
2. 在用户名文件夹下创建以 **任务名称** 命名的文件夹
3. 按照上述目录结构提交算子代码
4. 提交 Pull Request 到本仓库
