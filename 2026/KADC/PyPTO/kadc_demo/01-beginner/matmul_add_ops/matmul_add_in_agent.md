## 需求-1
请开发一个 PyPTO 算子：
- 算子名称：matmul_add
- 公式：$ y(a, b, c) = a @ b^T + c $
- 规格：

| 类型  | shape  | dtype  |
| ------------ | ------------ | ------------ |
| 输入 a| \[m, k\] | bfloat16  |
| 输入 b| \[n, k\] | bfloat16  |
| 输入 c| \[m, n\] | bfloat16  |
| 输出 y| \[m, n\] | bfloat16  |

- 精度标准：atol=0.0001, rtol=0.0078125
- 其中要求，kernel本身是动态的，m是动态轴
