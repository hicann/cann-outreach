## 需求-1
请开发一个 PyPTO 动态算子：
- 算子名称：add_abs
- 公式：$ y = a + |b| $
- 规格：

| 类型  | shape  | dtype  |
| ------------ | ------------ | ------------ |
| 输入 a| \[n, d\]  | float32  |
| 输入 b| \[n, d\]  | float32  |
| 输出 y| \[n, d\]  | float32  |

- 精度标准：atol=0.000025, rtol=0.005
- 动态轴：n轴
